@zyphox/tailwind-dynamic-colors
Tailwind v4 tool for generating dynamic color palettes entirely in CSS entirely using oklch!
Pick a color
Drag the slider to see the colors dynamically change.
Light Mode
Light mode will generate light tones on low numbers and dark tones on high numbers.
Example
Dark Mode
Inside dark containers, invert the color palette with the --color-dynamic-direction variable.
Type <number> (1: Normal -1: Invert)
Example --color-dynamic-direction: -1
Base colors
The --color-dynamic variable sets the color to use for the tones.
Type <color> (Any valid css color)
Example --color-dynamic: slateblue
Example --color-dynamic: #5acd6a
Example --color-dynamic: hsl(8.3, 53.5%, 57.8%)
Hue Shift
The --color-dynamic-hue-shift variable adjusts the hue progressively across tones, creating a gradient. Each tone add or subtracts this value, with tone 500 being the base hue.
Type <angle> (0-360)
Example --color-dynamic: blue; --color-dynamic-hue-shift: 10
Example --color-dynamic: red; --color-dynamic-hue-shift: 30
Global You can apply a global hue shift to all dynamic colors by setting the --color-dynamic-global-hue-shift variable. If you define --color-dynamic-hue-shift on an element it will override the global setting.
Type <angle> (0-360)
Chroma Scale
The --color-dynamic-chroma-scale variable adjusts the vibrancy of the colors. Setting it to 0 will be monochromatic while 1 will be full color. Use this to create a more muted palette. Defaults to 1.
Type <number> (0-1)
Example --color-dynamic: magenta; --color-dynamic-chroma-scale: 0.25
Example --color-dynamic: magenta; --color-dynamic-chroma-scale: 0.5
Example --color-dynamic: magenta; --color-dynamic-chroma-scale: 0.75
Global You can apply a global hue shift to all dynamic colors by setting the --color-dynamic-global-hue-shift variable. If you define --color-dynamic-hue-shift on an element it will override the global setting.
Type <angle> (0-360)
Text Color
On color classes are automatically generated by using the extreme opposite tone colors. For example, --color-dynamic-400 generates an --color-on-dynamic-400 which is set to --color-dynamic-950.
Important If you use the bg-dynamic-* class, it will automatically apply the text color
Overriding
The defaults should work for most scenarios, but you can override it by redefining the --color-on-* variables:
.color-dynamic { --color-on-dynamic-50: var(--color-dynamic-950); --color-on-dynamic-100: var(--color-dynamic-900); ... --color-on-dynamic-950: var(--color-dynamic-50); }
Containers
Container classes are generated which give you a consistent way to use the colors across your project. Good for things like badge, notifications, chips. It automatically applies the color-dynamic class so all you need to do is specify the color. There are three variants:
Light Mode
dynamic-container-bright
dynamic-container
dynamic-container-dim
Dark Mode
dynamic-container-bright
dynamic-container
dynamic-container-dim
Advanced Options
Each tone is generated with a hand crafted chroma values to ensure maximum visual consistency. It takes these values and multiplies it by the input colors chroma value, ensuring its never going above the possible gamut range. If you would like to override this list of modifiers or if you want to tweak individual tone chroma's, you can override it with the --color-dynamic-c-* variable.
:root { --color-dynamic-c-50: 0.21807065217391303; --color-dynamic-c-100: 0.21807065217391303; --color-dynamic-c-200: 0.41372282608695654; --color-dynamic-c-300: 0.6168478260869565; --color-dynamic-c-400: 0.9497282608695653; --color-dynamic-c-500: 1; --color-dynamic-c-600: 0.8824728260869564; --color-dynamic-c-700: 0.7248641304347826; --color-dynamic-c-800: 0.610054347826087; --color-dynamic-c-900: 0.49320652173913043; --color-dynamic-c-950: 0.36684782608695654; }
Same this applies to the lightness values --color-dynamic-l-* variable.
:root { --color-dynamic-l-50: 0.9778; --color-dynamic-l-100: 0.9456; --color-dynamic-l-200: 0.8811; --color-dynamic-l-300: 0.8267; --color-dynamic-l-400: 0.7422; --color-dynamic-l-500: 0.6478; --color-dynamic-l-600: 0.5733; --color-dynamic-l-700: 0.4689; --color-dynamic-l-800: 0.3944; --color-dynamic-l-900: 0.32; --color-dynamic-l-950: 0.2378; }
Additionally, there is a --color-dynamic-h-* modifier which is multiplied by the --color-dynamic-hue-shift. You could modify this if you want to make the hue shift more at the ends and less in the middle.
:root { --color-dynamic-h-50: 5; --color-dynamic-h-100: 4; --color-dynamic-h-200: 3; --color-dynamic-h-300: 2; --color-dynamic-h-400: 1; --color-dynamic-h-500: 0; --color-dynamic-h-600: -1; --color-dynamic-h-700: -2; --color-dynamic-h-800: -3; --color-dynamic-h-900: -4; --color-dynamic-h-950: -5; }
